# 💬 Real-Time Chatting App

A full-stack **real-time chat application** that enables instant messaging between users using **Socket.IO**, **Node.js**, and **React**. Designed with a responsive UI and secure authentication, this app allows seamless communication across devices.

---

## 🚀 Features


- 💬 **One-to-One Real-Time Messaging**
- 🟢 **Online/Offline Presence Indicators**
- 📦 **Socket.IO for Instant Updates**
- 📱 **Responsive UI with React +  Bootstrap**
  
---

## 🛠️ Tech Stack

### 🔧 Frontend:
- React.js
- Bootstrap 
- React Router

### ⚙️ Backend:
- Node.js
- Express.js
- Socket.IO
